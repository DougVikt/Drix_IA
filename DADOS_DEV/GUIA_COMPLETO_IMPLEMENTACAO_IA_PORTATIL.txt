 FASE 3 - CONFIGURAÇÃO DO POETRY (GERENCIADOR DE PACOTES)
================================================================================

  O Poetry é superior ao pip porque:
  - Garante que as versões das bibliotecas nunca entrem em conflito
  - Cria um arquivo poetry.lock que "trava" as versões
  - Permite reconstruir o ambiente em qualquer PC com poetry install

  3.1 Instalar o Poetry no WinPython (dentro do HD)

    Abra o WinPython Command Prompt.exe e execute:

      pip install poetry

  3.2 Configurar Portabilidade (CRUCIAL)

    Por padrão, o Poetry salva ambientes virtuais no AppData do PC hospedeiro.
    Execute estes comandos no terminal do WinPython para forçar o ambiente
    a ficar no HD:

      poetry config virtualenvs.in-project true
      poetry config cache-dir "./ia_system/poetry_cache"

  3.3 Inicializar o Projeto

    No terminal do WinPython, navegue até a raiz do HD e execute:

      cd [DRIVE]:\
      poetry init

    Siga as instruções interativas:
      - Package name: ia-portatil
      - Version: 0.1.0
      - Description: IA Portátil Independente com Aprendizado Contínuo
      - Author: (seu nome)
      - License: MIT
      - Define dependencies interactively? Yes

  3.4 Adicionar Dependências Core

    Ainda no terminal do WinPython, na raiz do HD:

      poetry add langchain chromadb ollama openai pyyaml fastapi uvicorn streamlit

    Isso criará o arquivo poetry.lock. Guarde-o - ele é seu "seguro"
    de reprodutibilidade.

  3.5 Arquivo pyproject.toml completo (para referência)

    [tool.poetry]
    name = "ia-portatil"
    version = "0.1.0"
    description = "IA Portátil Independente com Aprendizado Contínuo"
    authors = ["Seu Nome <email@exemplo.com>"]

    [tool.poetry.dependencies]
    python = "^3.10"
    langchain = "^0.1"
    chromadb = "^0.4"
    ollama = "^0.2"
    openai = "^1.0"
    pyyaml = "^6.0"
    fastapi = "^0.104"
    uvicorn = "^0.24"
    streamlit = "^1.30"

    [build-system]
    requires = ["poetry-core"]
    build-backend = "poetry.core.masonry.api"

================================================================================

  4.1 Baixar o Ollama

    Acesse: https://ollama.com/download
    Baixe a versão para Windows (ollama.exe).

  4.2 Colocar o binário no HD

    Copie o ollama.exe para: [DRIVE]:\ia_system\engine\

    do HD. O arquivo iniciar.bat forçará o uso do binário do HD.

  4.3 Configurar variável de ambiente dos modelos

    No iniciar.bat, usamos %~dp0 para capturar automaticamente a
    letra do drive (E:, F:, G: — muda conforme o PC):

      set OLLAMA_MODELS=%HD_PATH%ia_system\models

    do HD independente da letra. Assim os modelos baixados

import os
import sys
import yaml
import importlib
from pathlib import Path

# Carregar configuracoes
CONFIG_PATH = Path(__file__).parent / "config.yaml"
with open(CONFIG_PATH, "r", encoding="utf-8") as f:
    config = yaml.safe_load(f)

# Detectar automaticamente a raiz do HD (funciona em qualquer letra de drive)
HD_ROOT = Path(__file__).parent

# Sistema de aprendizado (RAG)
def atualizar_aprendizado():
    """Varre a pasta de licoes e atualiza o banco vetorial."""
    print("[IA] Verificando licoes novas no HD...")

    from langchain_community.document_loaders import DirectoryLoader, PyPDFLoader, TextLoader
    from langchain_community.embeddings import OllamaEmbeddings
    from langchain_community.vectorstores import Chroma
    from langchain.text_splitter import RecursiveCharacterTextSplitter

    lessons_folder = str(HD_ROOT / config["brain"]["lessons_folder"])
    memory_db = str(HD_ROOT / config["brain"]["memory_db"])

    # Carrega PDFs e TXTs
    loaders = [
        DirectoryLoader(lessons_folder, glob="*.pdf", loader_cls=PyPDFLoader),
        DirectoryLoader(lessons_folder, glob="*.txt", loader_cls=TextLoader),
    ]

    docs = []
    for loader in loaders:
        try:
            docs.extend(loader.load())
        except Exception:
            pass

    if not docs:
        print("[IA] Nenhuma licao nova encontrada.")
        return False

    # Divide em chunks para melhor indexacao
    splitter = RecursiveCharacterTextSplitter(
        chunk_size=config["brain"].get("chunk_size", 1000),
        chunk_overlap=200
    )
    chunks = splitter.split_documents(docs)

    # Cria/atualiza banco vetorial
    model_name = config["brain"].get("local_model", "qwen2.5:7b")
    embeddings = OllamaEmbeddings(model=model_name)

    db = Chroma.from_documents(
        documents=chunks,
        embedding=embeddings,
        persist_directory=memory_db
    )
    db.persist()
    print(f"[IA] Aprendizado atualizado! {len(chunks)} chunks indexados.")
    return True


# Filtro de seguranca (Security Bridge)
class SecurityBridge:
    """Controla o acesso da IA ao PC hospedeiro."""

    def __init__(self, cfg):
        self.cfg = cfg

    def can_access(self, target_path: str, mode: str = "read") -> bool:
        """Verifica se o caminho esta autorizado no config.yaml."""
        abs_target = os.path.abspath(target_path)

        # Se for dentro do proprio HD, acesso livre
        if abs_target.startswith(str(HD_ROOT)):
            return True

        # Se for no Host, checa lista de permissoes
        if mode == "write" and not self.cfg["security"].get("allow_host_write", False):
            return False

        allowed = self.cfg["security"].get("allowed_folders", [])
        for path in allowed:
            if abs_target.startswith(os.path.abspath(path)):
                return True

        return False

    def safe_read(self, path: str) -> str:
        """Le um arquivo do PC hospedeiro de forma segura."""
        if self.can_access(path, "read"):
            with open(path, "r", encoding="utf-8") as f:
                return f.read()
        return "ACESSO NEGADO: Caminho nao autorizado no config.yaml."


# Carregador de Skills (Plugins)
class SkillManager:
    """Gerencia o carregamento dinamico de skills da pasta skills/."""

    def __init__(self):
        self.skills = {}
        skills_path = HD_ROOT / "skills"
        if skills_path.exists():
            sys.path.insert(0, str(skills_path))
            for file in skills_path.glob("*_skill.py"):
                module_name = file.stem
                try:
                    module = importlib.import_module(module_name)
                    self.skills[module_name] = module
                    print(f"[IA] Skill carregada: {module_name}")
                except Exception as e:
                    print(f"[IA] Erro ao carregar skill {module_name}: {e}")

    def execute(self, skill_name: str, function_name: str, *args, **kwargs):
        """Executa uma funcao dentro de uma skill."""
        if skill_name in self.skills:
            func = getattr(self.skills[skill_name], function_name, None)
            if func:
                return func(*args, config=config, hd_root=HD_ROOT, **kwargs)
        return f"Skill {skill_name}.{function_name} nao encontrada."


# Busca contexto no banco vetorial
def buscar_contexto(query: str, k: int = 3) -> str:
    """Busca chunks relevantes no banco vetorial."""
    from langchain_community.embeddings import OllamaEmbeddings
    from langchain_community.vectorstores import Chroma

    memory_db = str(HD_ROOT / config["brain"]["memory_db"])
    model_name = config["brain"].get("local_model", "qwen2.5:7b")

    if not os.path.exists(memory_db):
        return ""

    embeddings = OllamaEmbeddings(model=model_name)
    db = Chroma(persist_directory=memory_db, embedding_function=embeddings)
    docs = db.similarity_search(query, k=k)

    return "\n\n".join([d.page_content for d in docs])


# Execucao do prompt
def perguntar(query: str) -> str:
    """Processa a pergunta do usuario e retorna a resposta da IA."""
    mode = config["operation"]["mode"]

    # Busca contexto nas licoes
    contexto = buscar_contexto(query)
    prompt_final = f"Contexto das licoes no HD:\n{contexto}\n\n---\n\nPergunta: {query}"

    if mode == "offline":
        import ollama
        model = config["brain"].get("local_model", "qwen2.5:7b")
        response = ollama.chat(model=model, messages=[
            {"role": "system", "content": "Voce e uma IA portatil com aprendizado continuo. Responda com base no contexto fornecido e no seu conhecimento geral."},
            {"role": "user", "content": prompt_final}
        ])
        return response["message"]["content"]

    else:
        from openai import OpenAI
        api_key = config["operation"].get("api_key", "")
        if not api_key or api_key == "SUA_CHAVE_AQUI":
            return "ERRO: Configure a api_key no config.yaml para usar o modo API."
        client = OpenAI(api_key=api_key)
        response = client.chat.completions.create(
            model="gpt-4",
            messages=[
                {"role": "system", "content": "Voce e uma IA portatil. Use o contexto das licoes do usuario para responder."},
                {"role": "user", "content": prompt_final}
            ]
        )
        return response.choices[0].message.content


# Interface de linha de comando
def iniciar_interface():
    """Modo chat interativo via terminal."""
    security = SecurityBridge(config)
    skills = SkillManager()

    print("\n" + "="*50)
    print("  IA PORTATIL - Modo: " + config["operation"]["mode"].upper())
    print("="*50)
    print("Comandos especiais:")
    print("  /aprender     - Forca atualizacao do aprendizado")
    print("  /ler <caminho> - Le um arquivo do PC (se autorizado)")
    print("  /skill <nome> <funcao> <args> - Executa uma skill")
    print("  /sair         - Encerra")
    print("="*50 + "\n")

    while True:
        try:
            entrada = input("\nVocê: ").strip()
        except (EOFError, KeyboardInterrupt):
            print("\nEncerrando...")
            break

        if not entrada:
            continue

        if entrada.lower() == "/sair":
            print("IA: Até logo!")
            break

        elif entrada.lower() == "/aprender":
            atualizar_aprendizado()

        elif entrada.lower().startswith("/ler "):
            caminho = entrada[5:].strip()
            print("IA:", security.safe_read(caminho))

        elif entrada.lower().startswith("/skill "):
            partes = entrada[7:].split()
            if len(partes) >= 2:
                skill_name = partes[0]
                func_name = partes[1]
                args = partes[2:]
                resultado = skills.execute(skill_name, func_name, *args)
                print("IA:", resultado)
            else:
                print("IA: Use: /skill <nome> <função> [args]")

        else:
            resposta = perguntar(entrada)
            print("IA:", resposta)

    from pathlib import Path

    def gerar_imagem(prompt, **kwargs):
        """Gera imagem via Stable Diffusion (offline) ou DALL-E (api)."""
        cfg = kwargs.get("config", {})
        hd_root = kwargs.get("hd_root", Path("."))
        workspace = hd_root / "workspace"

        if cfg.get("operation", {}).get("mode") == "offline":
            try:
                from diffusers import StableDiffusionPipeline
                import torch
                modelos = hd_root / "ia_system" / "models"
                pipe = StableDiffusionPipeline.from_pretrained(
                    str(modelos / "stable-diffusion-v1-5")
                )
                if cfg.get("local_resources", {}).get("use_gpu", True) and torch.cuda.is_available():
                    pipe.to("cuda")
                image = pipe(prompt).images[0]
                output = workspace / "imagem_gerada.png"
                image.save(str(output))
                return f"Imagem gerada e salva em: {output}"
            except Exception as e:
                return f"Erro ao gerar imagem offline: {e}. Tente modo API ou instale o modelo."
        else:
            return "Modo API para geracao de imagem - configure a chave da OpenAI ou Stability AI."

from pathlib import Path

HD_ROOT = Path(__file__).parent.parent
MODELS_DIR = HD_ROOT / "ia_system" / "models"
MODELS_DIR.mkdir(parents=True, exist_ok=True)

def download_model(name, repo_id, dest_subdir):
    dest = MODELS_DIR / dest_subdir
    if dest.exists():
        print(f"[OK] Modelo {name} já existe.")
        return
    print(f"Baixando {name}...")
    try:
        from huggingface_hub import snapshot_download
        snapshot_download(repo_id=repo_id, local_dir=str(dest))
        print(f"[OK] {name} baixado em {dest}")
    except Exception as e:
        print(f"[ERRO] Falha ao baixar {name}: {e}")
